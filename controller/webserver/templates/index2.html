On demand

Run one measurement

Choose one task below. Its status remains queued while the controller is processing it.

01 Ready

Poll system sensors

Read the Raspberry Pi system sensors and store a fresh health measurement.

Use this to check controller temperature and other system values without waiting for the schedule.
02 Ready

Voltage measurement

Capture the voltage values for the connected microbial fuel cells.

The active individual or series mode from General configuration is used for this measurement.
03 Ready

Resistive sweep

Run a complete load sweep to characterize the MFC power output.

A sweep can take longer than the other tasks. Keep the hardware connected until it finishes.
03 🚧 Under Construction

Resistive sweep

This feature is currently under development and is not yet available. It will be enabled in a future update.

🚧 Work in progress. The sweep functionality is being implemented and tested.
